T2, T3 and T4 can each be a mono synth, poly synth, or sampler.

Choose and edit a sound

  • PRESETS browses factory sounds and user slots. Open EDIT → VOICE to change the track type.
  • Press EDIT again for oscillator, tone, filter and other pages. Use ENV for envelopes, and LFO for modulation and the matrix.
  • To keep a sound, hold SAVE, turn PRESETS to choose a user slot, then let go.

Sample into a track

On a sampler track, hold REC and press SEL. Use EDIT → SAMPLE to set start, end and loop; use PITCH to set the sample’s root key.

Make a 303 line

On T2–T4, press SEQ twice to reach ACID. OCT+ makes a new line and OCT− mutates it. K1–K4 control density, whole notes, slides and accents.
